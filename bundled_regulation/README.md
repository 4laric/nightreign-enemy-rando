# bundled_regulation

Pre-patched `regulation.bin` for end-user deployment.

## What's here

| File             | Size  | Source           | Purpose                                                          |
|------------------|-------|------------------|------------------------------------------------------------------|
| `regulation.bin` | ~3 MB | MMV base + fixes | Drop-in replacement carrying every param patch the rando needs   |

This is **MMV's regulation.bin** as a base (so cross-game and DLC chrs
have their NpcParam / AtkParam / behavior-param entries registered),
with the v0.28.x balance + safety patches applied on top:

- **NpcParam HP overrides** (54 cps, 367 variant rows — see
  `dev/emit_hp_overrides.py` / `data/npcparam_hp_overrides.csv`).
  Caps heritage/SoTE-import HP at vanilla NR p75 per tier so
  Furnace Golem etc. stop being slog sponges.
- **AtkParam_Npc damage overrides** (70 attacks, 18 cps — see
  `dev/emit_atk_overrides.py` /
  `data/atkparam_npc_damage_overrides.csv`). Per-attack cap at
  vanilla NR p75 max-attack; kills the Artorias 999-damage move
  and the PCR 800 hit without flattening the rest of those bosses'
  kits.
- **NpcParam reward / getSoul overrides** (see
  `data/npcparam_reward_overrides.csv`,
  `data/npcparam_getsoul_overrides.csv`). Per-tier floors so no
  miniboss-and-above placement reads as a "stiffed kill."
- **NpcParam contamination fix** (see
  `regulation_fixes/NpcParam_decontaminate_smithbox.csv` and
  `regulation_fixes/regulation_contamination_npcparam.csv`). 877
  rows healed back to MMV's intended `chaosMatchingCorrectParamId`
  and `hp` values; every other field byte-identical to the live
  regulation.
- **LotResultSmallBaseAndSpot NB whitelist** (see
  `regulation_fixes/LotResultSmallBaseAndSpot_nb_whitelist_smithbox.csv`).
  Redirects the 22 dedicated NB-arena IDs through the active
  whitelist in `data/nb_encounter_whitelist.json` (commander bans +
  NK/Dancer/Morgott phase-transition bans excluded).
- **NpcThinkParam aggro / Bullet lamprey snipe fixes** (see
  `regulation_fixes/NpcThinkParam_aggro_fix_smithbox.csv`,
  `regulation_fixes/Bullet_lamprey_snipe_fix_smithbox.csv`). Pre-
  existing minor patches carried forward.

The end-user effect is a **single file copy** instead of a stack of
Smithbox imports.

## Deployment

Drop `regulation.bin` into your me3 mod profile at the root of the
package, mirroring the game directory layout:

```
<me3 profile>/<package>/regulation.bin
```

me3 substitutes it at load time. Nightreign reads params from this
copy instead of the install's vanilla `regulation.bin`.

## Why we bundle MMV's regulation (not vanilla NR + patches)

Two reasons stack:

1. **MMV mode requires MMV's regulation anyway.** Enabling MMV
   cross-game imports in the rando makes the engine place chrs
   (c8300 Dragonslayer Armor, c8500 Manus, etc.) whose NpcParam /
   BehaviorParam rows only exist in MMV's regulation. Without MMV's
   regulation present, those references CTD the game on cell load.
   Bundling MMV's regulation lets the rando run with MMV mode ON by
   default without requiring the user to install MMV separately.

2. **Patch authorship is easier on a single base.** All override
   CSVs target row IDs that exist in MMV's regulation. Targeting
   vanilla NR's regulation would skip the cross-game rows entirely
   (they aren't in vanilla); we'd need two separate patch streams.

The companion `bundled_aicommon/aicommon.luabnd.dcx` is also MMV's
(strict superset of vanilla NR's) for the same reason — DLC chrs'
AI scripts reference goal-table constants only defined there.

## When this might change

The companion `bundled_aicommon/aicommon.luabnd.dcx` was previously
flagged as "until we confirm DLC chrs work against ER's aicommon."
As of v0.28.x playtest, that's **confirmed: MMV's aicommon is
required, not just preferred**. ER's vanilla aicommon is not a
substitute — substituting it produces silent goal-table-registration
failures → DLC chrs freeze on spawn. The same playtest confirmed
`bundled_sfx/sfxbnd_c0000.ffxbnd.dcx` is also required for cross-game
chr particle effects.

The three MMV-derived bundles (regulation + aicommon + sfx) ship
together as the canonical asset base. Splitting them is no longer
on the roadmap.

## Verifying integrity

Format: 16-byte AES IV + AES-encrypted BND4 archive (FromSoftware's
regulation format). Size should be approximately 3 MB. Smaller
suggests a truncated download; larger suggests an uncompressed dump.

```
ls -lh bundled_regulation/regulation.bin   # ~3 MB
od -An -t x1 -N 16 bundled_regulation/regulation.bin
# First 16 bytes should be all 00s (the IV padding).
```

## Regeneration

The patched regulation is **not** generated by a script in this repo
— it is produced by hand via Smithbox by:

1. Open MMV's vanilla `regulation.bin` in Smithbox.
2. Paste-overlay each CSV in `regulation_fixes/` (read its README
   for ordering — decontamination first, then overrides, then NB
   whitelist).
3. Paste-overlay `data/npcparam_hp_overrides.csv`,
   `data/atkparam_npc_damage_overrides.csv`,
   `data/npcparam_reward_overrides.csv`,
   `data/npcparam_getsoul_overrides.csv` for the balance pass.
4. Save the regulation back out.
5. Drop the result here, replacing the existing `regulation.bin`.

A Python-side regulation-patching pipeline is on the followup list
so re-emitting the bundled regulation becomes one command. Until
that lands, the file ships as a snapshot.
