# data/ — engine data catalogs

Static JSON/CSV catalogs the engine and pipeline load at run time. Most
files here are **generated by the `dev/` tools from vanilla game data —
regenerate with the tool, don't hand-edit.** The hand-maintained exceptions
(tuning lists, pack manifests with playtest notes) are called out below.

## Core engine catalogs (read at startup by `engine/load_data.py`)

- `nr_enemy_roster.json` — every placeable NpcParam row. The roster.
- `nr_enemy_tags.json` — per-c-prefix tier/hp/anim/size/locomotion tags; the
  engine's enemy database.
- `placement_budget.json` — per-map slot populations, caps, and exclude
  sets. Generated by `dev/extract_placement_budget.py`.
- `nr_slot_inventory.json` / `nr_slot_metadata.json` — slot tile positions
  and per-slot metadata. Generated by `dev/emit_slot_inventory.py` /
  `dev/emit_slot_metadata.py`.

## Slot geometry & populations

`slot_terrain.json`, `slot_poi_clusters.json`, `slot_repositions.json`,
`nr_all_part_positions.json`, `nr_all_slots.json`, `nr_boss_slots.json`,
`nr_starting_encampments.json`, `nr_named_locations.json`, and the
`nr_*_slots.json` constraint lists — generated by `dev/build_slot_terrain.py`,
`dev/build_slot_poi_clusters.py`, `dev/build_slot_repositions.py`,
`dev/build_part_positions.py`, `dev/extract_msb_slots.py`, and the
`dev/audit_*` sweeps.

## Night-boss / Nightlord catalogs

`nightlord_pools.json`, `nightlord_expedition_table.json`,
`nightreign_arena_structure.json`, `nightlord_bosses_*.json`,
`nb_encounter_whitelist.json` (`dev/emit_nb_encounter_whitelist.py`),
`nb_wave_bypass_flags.json` (`dev/build_nb_wave_bypass_flags.py`),
`evergaol_wake_entities.json` / `stamped_boss_wake_entities.json` /
`stamp_test_wake_entities.json` (`dev/build_evergaol_wake_entities.py`,
`dev/stamp_name_marker_boss_wakes.py`).

## Caps, drops, and regulation overrides

- `cap_groups.json` — shared placement-cap groups (read by
  `engine/cap_groups.py`).
- `npcparam_hp_overrides.csv`, `atkparam_npc_damage_overrides.csv`,
  `npcparam_getsoul_overrides.csv`, `npcparam_reward_overrides.csv` —
  generated by `dev/emit_hp_overrides.py`, `dev/emit_atk_overrides.py`,
  `dev/emit_getsoul_overrides.py`, `dev/emit_reward_overrides.py`.
  **Do not hand-edit; staleness is test-locked** (`tests/test_hp_overrides.py`
  etc.). Note the runtime getSoul/reward passes in `npcparam_getsoul_fill.py`
  / `npcparam_reward_fill.py` are the per-seed companions to these CSVs.
- `has_reward_overrides.json` (`dev/emit_has_reward.py`),
  `drop_rarity_by_tier.json` / `regulation_pools.json` (inputs to
  `drop_tiers.py`).

## Pack manifests (hand-maintained — playtest notes live in `_meta`)

- `heritage_pack.json` — cross-game heritage roster/tags. Regenerate the
  mechanical parts with `dev/build_heritagae_pack.py` (the `heritagae`
  filename typo is historical — don't "fix" it).
- `mmv_imports.json` — MMV cross-game import manifest. Ships with
  `_meta.enabled=false` intentionally (CTD risk without MMV installed).
- `phase_transition_imports.json`, `phase1_v0.25.0_stubs.json`,
  `batch_import_plan_comprehensive.json` — heritage/import planning data.

## Vanilla reference dumps (read-only inputs, not tuned by hand)

`NpcParam.csv` (9.5 MB vanilla NpcParam export — note the *live* bundled
regulation differs from this dump; runtime passes read the live reg),
`Elden_Ring_Nightreign_map_patterns.csv`, `vanilla_*.json` tile/pattern
frequencies (`dev/derive_tile_data.py`), `msb_tile_probability.json`,
`chr_to_nameid.json` (healthbar name catalog), `valid_think_param_ids.json`,
`wakeup_chrs.json`, `scripted_intro_chrs.json`, `entrance_animations.json`.

## Tuning lists (hand-maintained)

`variant_prune_list.json` / `variant_prune_keep.json` /
`variant_restrict_list.json`, `trash_banned_variants.json`,
`reconstructed_trash.json`, `vanilla_promotions_v1.json`,
`nr_roster_subtypes.json`, `backstab_tiers.json`, `t1_anchors.json`.
`title_pool.json` is a stub shipped for future use — see
`title_pool_README.md`.

## snapshots/

Pre-built `load_data` snapshots (`vanilla_only`, `vanilla_plus_heritage`,
`everything_enabled`) used by `tests/test_load_data_lock.py` to lock startup
loader behavior. Regenerate only deliberately.
