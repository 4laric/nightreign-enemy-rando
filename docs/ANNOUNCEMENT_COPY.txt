LONG (Reddit r/Eldenring or r/Nightreign, ~1500 chars)
------------------------------------------------------

I've been quietly iterating on my Nightreign enemy randomizer for a
while, and it's finally in a state I'm happy to push.

What it does: shuffles every enemy and boss in the world. Each swap
target is constrained by the original occupant's size, locomotion type,
and animation library — so you don't get a Mountaintop Ice Dragon
spawning in a hallway built for one Wandering Noble. Mounted knights
become other mounted knights, dragons become other dragons, multi-part
encounters get cluster-shape-matched replacements.

What's new since the early versions:

- Zero-setup install. 300 vanilla map files ship in the bundle, so no
  UXM-unpacking your own game. Install, point output at your me3
  profile, Randomize. Double-click launchers, no terminal needed.
- Night Bosses actually work now. The 19 Night 1 / Night 2 arenas run a
  streamlined spawn template, so swapped bosses spawn, fight, and
  advance the night reliably instead of hanging mid-cinematic. Marquee
  bosses are guaranteed an appearance per seed at varied locations.
- A run of fresh-install reliability fixes — first-launch hangs, text
  encoding crashes, the works.

It still has the things it always had: an Oops! All mode (every slot
becomes one chosen enemy — Maris Tendril Nightreign is a real
experience), spoiler logs for every roll, and the cursed visual
chimeras that happen when NPCParam attachment fields don't fully sync,
which are 100% intentional and embraced.

Every roll has a seed, so you can share a cursed one or race a friend.
